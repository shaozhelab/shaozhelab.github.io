This site collects my work on post-training, from supervised fine-tuning to preference and policy optimization. Each project builds an end-to-end pipeline, uses ablations to understand what drives its behavior, and explains the mechanisms in writing.

Current projects:

- **nanoPO**: minimal, readable implementations of the policy-optimization algorithms behind LLM post-training, starting with PPO.
- **grounded-refusal**: post-training and diagnostic evaluation for evidence-grounded refusal in QA.

The code for every project is public on GitHub.
